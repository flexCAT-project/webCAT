In Step 2, first select the IRT model that was used to obtain the item parameters in the item bank information file.

Second, select the type of CAT that is required: If a fixed-length CAT is selected, the number of items (e.g., the test length) must also be specified. If a variable-length CAT is selected, the required level of measurement precision should be specified (default is \(SE(\hat\theta) = 0.3\)).

Third, the item parameterization must be specified (i.e., which parameters define the item response function; varies among different softwares).

The survey/test is generated using the mirtCAT::mirtCAT() function with the following inputs: criteria = "MI" or criteria = "Drule" for unidimensional and multidimensional tests respectively, start_item = "MI" for first item selection, and method = "EAP" for ability estimation. Note

For the two examples, configuration files have already been created.

For the TCAT, a fixed-length CAT of 10 items was set up and the item bank was calibrated using a 2PL model.

For the PPSE, a variable-length CAT with stopping rule \(SE(\hat\theta) = 0.3\) was set up and the item bank was calibrated using a graded response model.
